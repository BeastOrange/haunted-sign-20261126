A cautionary door sign designed to prevent unexpected outages caused by frightening the spectral system administrator residing inside the facility.

### Sign Text

WARNING: THE GHOST IN RACK 4 HAS ROOT ACCESS. KNOCK FIRST - IT REBOOTS WHEN STARTLED.

### Running

Generate the sign output by running:

```bash
python3 main.py
```

By default, the script writes to `/output/entry.txt`. You can supply an optional file path argument or set the `ENTRY_OUTPUT` environment variable to test locally.
